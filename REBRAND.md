# SleepCoach → Dayvera compatibility

Dayvera's app display name, source module, targets, project, shared scheme, documentation and GitHub repository use the new name. The tagline is **Build a stronger everyday.**

The installed app keeps `com.momoai.personalassistant.sleepcoach` so the rebrand is an update to the same app and container. The test bundle retains its identifier as well. `LegacyCompatibility` contains the old Calendar ownership marker and persisted alarm/Calendar keys needed for safe verification and Undo. No unrelated Calendar items are modified. The old exercise cache is copied to the Dayvera cache path only after it decodes successfully; the original remains available for recovery.

`DayveraTests/Fixtures/legacy-workouts.store` was generated by the original SleepCoach module before renaming. It contains only two deterministic synthetic records. The migration test opens this store using the renamed module plus the additive nutrition schema, checks the original workout UUID, notes and Health-export state, and writes a new meal. Keep this fixture as a historical compatibility artifact; do not regenerate it from the new module.

Existing screenshot images may show the pre-rebrand interface. The new nutrition QA captures identify the current release. Git history is not rewritten.

The local checkout is relocated only after all tests and GitHub operations finish, with explicit workspace access for the new path. No domain purchase or App Store listing is included.
